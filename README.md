# Pralay Kavach

## Overview

Pralay Kavach is a flood risk assessment and evacuation support platform developed to enhance disaster preparedness and response. The system utilizes real-time weather and geospatial data to analyze flood-prone conditions, provide location-aware risk insights, and assist users in identifying safe zones during emergencies.

Designed with a focus on accessibility and reliability, the platform aims to support informed decision-making by delivering timely information that can help reduce the impact of flood-related disasters on communities.

## Key Features

* Real-time weather data integration
* Flood risk assessment and monitoring
* Safe zone identification using geospatial information
* Interactive map-based visualization
* Location-aware evacuation support
* Responsive and user-friendly interface
